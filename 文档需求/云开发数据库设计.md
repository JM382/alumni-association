# 云开发数据库设计文档

> 依据当前仓库 `cloudfunctions/**/index.js` 中实际读写逻辑整理，用于建表、索引与后续迭代对齐。  
> 若线上历史数据存在字段缺失，以云函数中的兼容逻辑为准。

---

## 1. 约定

| 项 | 说明 |
|----|------|
| 主键 | 各集合默认使用云数据库自动 `_id` |
| 用户标识 | 业务上统一使用 `user_id`（与 `users` 文档的 `user_id` 或 `_id` 对齐）；部分集合字段名为 `userId`，含义相同 |
| 时间 | 未特别说明时，使用 `db.serverDate()` 写入服务端时间 |
| 身份 | `users.identity` 常见取值：`visitor`、`alumni`、`company`、`expert` |

**身份一致性约束（新增）**：

- 前端用于展示的身份文本（如“校友·企业·专家”）应以 `authApplications` 的 `approved` 结果为主，并与 `users.identity` 合并展示。  
- `users.identity` 可视为“快速标识/兼容字段”，不应单独作为所有页面身份展示的唯一来源。  
- 电子校友卡可用性判定应同时考虑：`users.identity === 'alumni'` **或** `authApplications` 存在 `category='alumni' && status='approved'`。  
- 任何新页面涉及身份展示时，需复用同一口径，避免“我的、个人主页、卡包”显示不一致。

## 2. 集合总览

| 集合名 | 用途 | 主要云函数 |

| `authApplications` | 校友/企业/专家认证申请与审核 | authApplications |
| `alumni_cards` | 电子校友卡 | alumniCard |
| `privacy_settings` | 隐私开关（一对一） | updatePrivacySettings |
| `notification_settings` | 消息通知开关（一对一） | updateNotificationSettings |
| `points_logs` | 积分流水 | points、events |
| `donations` | 捐赠记录 | donations、points |
| `membership_orders` | 会员订单 | membership |
| `notifications` | 互动类通知 | notifications、circle |
| `circle_posts` | 校友圈动态 | circle |
| `circle_likes` | 动态点赞 | circle |
| `circle_comments` | 动态评论 | circle |
| `follows` | 关注关系 | social |
| `conversations` | 私信会话 | social |
| `messages` | 私信消息 | social |
| `orders` | 我的订单（占位业务） | orders |
| `events` | 活动 | events |
| `event_signups` | 活动报名 | events |
| `resource_posts` | 资源求助/发布（分类） | resources |
| `resource_comments` | 资源帖评论 | resources |
| `resource_likes` | 资源帖点赞 | resources |

## 3. 分集合字段说明

### 3.1 `users`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `_id` | string | 是 | 文档 ID |
| `openid` | string | 是 | 微信 openid，唯一 |
| `user_id` | string | 建议 | 业务用户 ID；老数据可能仅有 `_id` |
| `nickname` | string | 否 | 昵称 |
| `avatarUrl` | string | 否 | 头像 |
| `identity` | string | 否 | 身份枚举 |
| `schoolId` | string | 否 | 学校 ID |
| `schoolName` | string | 否 | 学校名称 |
| `major` | string | 否 | 专业 |
| `enterYear` | string/number | 否 | 入学年份 |
| `graduationYear` | string | 否 | 毕业年份 |
| `bio` | string | 否 | 简介 |
| `city` | string | 否 | 城市 |
| `mobile` | string | 否 | 手机（个人信息页） |
| `email` | string | 否 | 邮箱 |
| `gender` | string | 否 | 性别 |
| `birthday` | string | 否 | 生日 |
| `realName` | string | 否 | 真实姓名（认证同步等） |
| `createTime` | date | 否 | 创建时间 |
| `lastLoginTime` | date | 否 | 最近登录 |
| `pointsBalance` | number | 否 | 积分余额 |
| `pointsUpdatedAt` | date | 否 | 积分更新时间 |
| `membershipLevel` | string | 否 | `none` / `vip` / `svip` |
| `membershipExpireAt` | date | 否 | 会员到期时间 |
| `membershipUpdatedAt` | date | 否 | 会员信息更新时间 |

**索引建议**：`openid`（唯一或普通）；`user_id`；查询校友列表时 `identity` + `schoolName` + `enterYear` + `major` 视查询组合建复合索引。

---

### 3.2 `admins`

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | 主键 |
| `openid` | string | 管理员微信 openid |
| `name` | string | 展示名 |
| `level` | string | `super_admin` / `domain_admin` |
| `scopes` | array\<string\> | 如 `alumni_audit`、`company_audit`、`expert_audit` |
| `disabled` | bool | 是否禁用 |
| `status` | string | 与禁用态配合使用 |

---

### 3.3 `authApplications`

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | 主键 |
| `userId` | string | 申请人 user_id |
| `openid` | string | 申请人 openid |
| `category` | string | `alumni` / `company` / `expert` |
| `status` | string | `pending` / `approved` / `rejected` / `canceled` |
| `alumniInfo` | object | 校友资料包 |
| `companyInfo` | object | 企业资料包 |
| `expertInfo` | object | 专家资料包 |
| `reviewerId` | string | 审核人（admins._id） |
| `reviewTime` | date | 审核时间 |
| `rejectReason` | string | 打回原因 |
| `remarks` | string | 备注（含自动作废说明等） |
| `createdAt` | date | 创建时间 |
| `updatedAt` | date | 更新时间 |

子对象字段以 `buildPayloadByCategory` 与兼容迁移逻辑为准（校友含 `realName`、`studentId`、`school`、`college`、`major`、`enterYear`、`contactMobile`、`contactEmail`、`certImages` 等）。

**索引建议**：`userId`+`category`；`openid`+`category`；`status`+`category`+`updatedAt`（列表）。

### 3.11 `circle_posts` / `circle_likes` / `circle_comments`

**`circle_posts`**：`userId`、`openid`、`content`、`images`、`video`、`likeCount`、`commentCount`、`visible`、`location`、`onlyAlumni`、`createdAt`、`updatedAt`、`extra`。

**`circle_likes`**：`postId`、`userId`、`openid`、`createdAt`。

**`circle_comments`**：`postId`、`userId`、`openid`、`content`、`parentId`、`replyToUserId`、`visible`、`createdAt`、`extra`。

---

### 3.12 `follows`

| 字段 | 类型 | 说明 |

### 3.13 `conversations` / `messages`

**`conversations`**：`type`（如 `private`）、`userIds`（长度为 2 的数组）、`lastMessageText`、`lastMessageAt`、`lastMessageSenderId`、`unreadMap`（userId→未读数）、`createdAt`、`updatedAt`。

**`messages`**：`conversationId`、`fromUserId`、`toUserId`、`contentType`、`text`、`media`、`status`、`createdAt`、`extra`。

### 3.15 `events` / `event_signups`

**`events`**：`title`、`coverImage`、`brief`、`startTime`、`endTime`、`location`、`participantCount`、`maxParticipants`、`status`、`ticketOptions`（含 `ticketId`、`name`、`price` 等）、`protocolText`、`updatedAt`。

**`event_signups`**：`eventId`、`userId`、`ticketId`、`ticketName`、`amount`、`status`、`realName`、`mobile`、`peopleCount`、`remark`、`signInStatus`、`signInTime`、`signInCode`、`pointsAwarded`、`pointsReverted`、`canceledAt`、`createdAt`、`updatedAt`、`extra`。

---

### 3.16 `resource_posts` / `resource_comments` / `resource_likes`

**`resource_posts`**：`category`（`help`/`publish`）、`userId`、`title`、`content`、`tag`、`contact`、`images`、`video`、`likeCount`、`commentCount`、`status`、`createdAt`、`updatedAt`。

**`resource_comments`**：`postId`、`userId`、`content`、`parentId`、`replyToUserId`、`status`、`createdAt`。

**`resource_likes`**：`postId`、`userId`、`createdAt`。

## 4. 关系说明（简图）

```
users (user_id) ─┬─ authApplications
                 ├─ points_logs / donations / membership_orders
                 ├─ privacy_settings / notification_settings (1:1)
                 ├─ circle_posts / circle_likes / circle_comments
                 ├─ follows / conversations / messages
                 ├─ event_signups → events
                 └─ resource_posts / resource_comments / resource_likes

admins ── authApplications (审核)
```
