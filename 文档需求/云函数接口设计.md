# 云函数接口设计文档

> 小程序通过 `wx.cloud.callFunction({ name, data })` 调用。  
> 除特别说明外，云函数内使用 `cloud.getWXContext().OPENID` 识别当前用户。  
> 统一返回风格：成功多为 `{ success: true, ... }`，失败为 `{ success: false, error: '...' }`；`getUserInfo` 使用 `{ code, data, msg }`。

---

## 1. 调用约定

| 项 | 说明 |
|----|------|
| 云函数名 | `name` 字段，与 `cloudfunctions` 目录名一致 |
| 路由 | 多数云函数用 `data.action` 区分子接口；无 `action` 时见各节默认值 |
| 鉴权 | 需登录的云函数依赖用户已在 `users` 中有 openid 对应记录 |

---

## 2. `login`

**用途**：微信登录，创建/更新 `users`。

| 请求字段 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| `nickname` | string | 否 | 昵称 |
| `avatarUrl` | string | 否 | 头像 |

**返回**：`{ success: true, user: { user_id, ... } }` 或 `{ success: false, error }`。

---

## 3. `getUserInfo`

**用途**：按当前 openid 读取 `users` 整条文档。

**请求**：无参数或空对象。

**返回**：

| 字段 | 说明 |
|------|------|
| `code` | `0` 成功，`-1` 失败 |
| `data` | 用户文档；无用户时 `{}`；成功时含 `user_id` |
| `msg` | 提示信息 |

---

## 4. `updateUserProfile`

**用途**：更新当前用户个人信息；支持注销。

| 请求字段 | 类型 | 说明 |
|----------|------|------|
| `deregister` | bool | `true` 时删除当前用户 `users` 文档 |
| `nickname` | string | 可选 |
| `mobile` | string | 可选 |
| `email` | string | 可选 |
| `gender` | string | 可选 |
| `birthday` | string | 可选 |
| `city` | string | 可选 |
| `bio` | string | 可选 |
| `avatarUrl` | string | 可选 |

**返回**：`{ success: true, user }` 或 `{ success: false, error }`。

---

## 5. `updatePrivacySettings`

**用途**：读写 `privacy_settings`（无则新增）。支持仅查询不落库。

| 请求字段 | 类型 | 说明 |
|----------|------|------|
| `action` | string | 可选。`get`：只读当前用户开关，无记录时返回与前端一致的默认值；不传则按下方字段更新或新增 |
| `phoneVisible` | bool | 可选 |
| `emailVisible` | bool | 可选 |
| `workVisible` | bool | 可选 |
| `searchable` | bool | 可选 |
| `dmFromNonFriend` | bool | 可选 |
| `circleFriendsOnly` | bool | 可选 |

**返回**：`{ success: true, settings }`。

## 7. `authApplications`

**默认**：无合法 `action` 时失败。

| action | 说明 | 主要请求字段 | 返回要点 |
|--------|------|----------------|----------|
| `submit` | 提交/更新认证 | `category`，`payload`（表单） | `applicationId`、`updated`/`created` |
| `myStatus` | 三类认证状态 | 无 | `data.alumni/company/expert` |
| `myHistory` | 单类历史一条 | `category` 可选 | `list` |
| `myAdminProfile` | 是否管理员 | 无 | `isAdmin`、`admin` |
| `adminList` | 管理端列表 | `category`、`status`、`page`、`pageSize` | `list`、`total`；待审会服务端去重 |
| `adminDetail` | 单条详情 | `applicationId` | `data` |
| `adminReview` | 审核 | `applicationId`、`reviewAction`（`approve`/`reject`）、`rejectReason`（打回）、`remarks` | `success` |

**注意**：审核结果字段必须使用 `reviewAction`，不要用 `action` 表示通过/打回，否则会与云函数路由字段 `action` 冲突。

## 19. 错误与调试

| 现象 | 可能原因 |
|------|----------|
| `用户不存在` | 未先 `login` 写入 `users` |
| `无管理员权限` | `admins` 无当前 openid 或 scope 不足 |
| `不支持的 action` | `data.action` 拼写错误或云函数未部署最新版 |
