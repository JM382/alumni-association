## 毕业论文（设计）开题报告

### 一、选题的目的和意义

当前高校校友工作普遍面临数据分散、互动不足、服务单一的现实问题，传统校友系统多以信息发布为主，缺乏对校友关系链的深度激活与价值挖掘。本课题旨在设计并实现一套基于微信小程序的校友会综合服务平台，其核心目的在于构建一个集身份认证、福利展示、社交互动、活动与服务入口于一体的轻量化数字枢纽，从而有效整合校友资源，提升校友会管理效率与服务温度。

本系统的意义在于：一方面，通过小程序即开即用的便利性降低使用门槛，结合资讯、福利、活动报名与校友互动等能力，切实增强校友归属感与社群凝聚力；另一方面，系统沉淀的校友数据与行为数据可为高校校友工作数字化提供实践样本。技术上采用 **微信云开发（云数据库、云存储、云函数）**，降低运维成本并与微信生态深度集成，为同类社会组织数字化转型提供可复用的实践路径。

---

### 二、本题的研究现状及开题前的准备工作（图书馆里面 CNKI）

#### 1、研究现状

通过对中国知网及相关技术社区的文献调研发现，校友会系统的建设已从早期的 PC 网站、独立 App 向微信生态迁移，利用其庞大的用户基数与便捷入口已成为主流趋势。现有系统功能逐渐从单向信息发布转向活动报名、电子校友卡、在线捐赠等基础服务集成，但在商业化福利生态整合、深度社交与即时沟通、以及基于云开发的轻量级全栈实现方面仍各有侧重。

技术上，多数系统采用 Java 或 Python 等传统后端框架；**微信云开发**作为一种全栈解决方案，因其免运维、低成本、与微信生态深度集成等特点，正成为轻量级应用开发的有力选择，其在云函数业务拆分、数据库权限与索引设计上的实践仍需在真实项目中验证与总结。

#### 2、研究挑战

**主要因素**：系统需在有限开发周期内平衡功能丰富性与用户体验的轻量化，并兼顾不同年龄段校友的操作习惯；同时，如何设计合理的运营与审核机制以保证内容合规、用户持续活跃，是产品设计阶段需考虑的问题。

**技术因素**：核心难点包括构建**可靠的多类型身份认证与管理员审核流程**，保障校友隐私数据安全；在云开发架构下合理划分云函数职责、设计集合与索引，并应对活动报名、动态互动等场景下的并发与一致性需求。

### 四、毕业论文（设计）的主要内容（**已按源码实现修订**）

本设计完成「基于微信云开发的校友会服务平台」从需求分析到功能实现与文档沉淀的全过程，**与当前程序实现一致**的主要内容包括：

1. **需求分析与总体设计**  
   明确普通用户、校友、企业/专家申请者、**认证审核管理员**等角色；梳理核心用例；给出基于微信云开发的技术架构（小程序端 + 云函数 + 云数据库 + 云存储），并完成数据库与接口层面的设计文档。

2. **微信小程序前端实现**  
   采用微信小程序原生技术栈（WXML、WXSS、JavaScript），实现多 Tab 页面结构，主要包括：**首页、校友福利、资讯、校友圈、我的**等；校友圈内含**动态流、活动列表、找校友**等子模块；个人中心集成**个人信息、认证与申请、电子校友卡/卡包、积分、通讯录、我的活动、订单、捐赠、人脉、资源求助与发布、会员中心、账号与消息/隐私设置**等功能入口；并实现**校友圈动态详情、活动详情与报名、私信聊天、他人个人主页**等页面流程。

3. **云函数与云数据库业务实现**  
   使用云函数封装业务逻辑，云数据库存储用户、认证申请、动态、活动与报名、订单、捐赠、积分流水、会员订单、关注与私信、通知等数据。重点实现：**校友/企业/专家认证申请与管理员审核（含待审去重与状态同步）**、**电子校友卡生成与展示**、**活动发布与报名、签到及与积分联动**、**捐赠记录与积分奖励规则**、**会员信息（如 VIP/SVIP）展示**、**校友圈动态与点赞评论**、**关注与私信会话**、**互动类通知**等。

4. **管理端能力（轻量化）**  
   在小程序内提供**管理员入口**，完成**认证审核列表、详情与通过/打回**等操作，并与用户端「认证与申请」状态联动，形成闭环。

5. **测试与文档**  
   对主要业务流程进行功能验证；整理**数据库设计说明**与**云函数接口说明**；最终形成可运行系统、设计类文档与毕业论文正文材料。
