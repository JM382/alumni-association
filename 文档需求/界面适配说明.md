# 小程序界面多机型适配说明

本文档说明如何让界面在不同机型（不同屏幕宽度、刘海屏、底部横条）上表现一致、不被遮挡。

---

## 一、设计稿与单位：用 rpx

- **设计稿宽度**：按 **750px** 出图（或 375pt）。
- **尺寸与间距**：一律用 **rpx**。  
  - 小程序会按「屏幕宽度 / 750」换算，不同宽度机型自动等比缩放。  
  - 例如：设计稿上 100px 宽 → 写 `100rpx`；字体 28px → 写 `28rpx`。
- **不要用 px**：px 是物理像素，小屏会显得大、大屏会显得小，除非是 1px 边框可用 `1rpx` 或 `1px`（按需）。

**总结**：布局宽高、字体、圆角、间距都用 **rpx**，是适配所有机型的基础。

---

## 二、安全区域（刘海、状态栏、底部横条）

iPhone X 及以后、部分 Android 机型有「刘海」和底部「横条」，内容不能压在这些区域上。

### 2.1 在 WXSS 里用 env()

- **顶部**：`padding-top: env(safe-area-inset-top);`  
  用于自定义导航栏时，给内容留出状态栏高度。
- **底部**：`padding-bottom: env(safe-area-inset-bottom);`  
  用于有底部 TabBar 或固定底部按钮的页面，避免内容被横条遮挡。

兼容旧版基础库可加 `constant()` 前缀（在前一行）：

```css
padding-bottom: constant(safe-area-inset-bottom);
padding-bottom: env(safe-area-inset-bottom);
```

### 2.2 本项目已做的处理

- **app.wxss**：`page` 已加 `padding-top` / `padding-bottom` 的 safe-area，全局生效。
- **有 TabBar 的页面**（如「我的」）：内容区 `padding-bottom` 使用  
  `calc(120rpx + env(safe-area-inset-bottom))`，避免列表被 TabBar + 横条挡住。
- **custom-tab-bar**：容器已加 `padding-bottom: env(safe-area-inset-bottom)`，TabBar 会整体上移，不被横条遮挡。

---

## 三、页面结构建议

1. **根节点**：用 `min-height: 100vh` 保证至少一屏高；需要时加 `box-sizing: border-box`。
2. **有底部 TabBar 的页面**：根容器 `padding-bottom` 建议为  
   `calc(120rpx + env(safe-area-inset-bottom))`（或使用全局类 `.page-with-tabbar`）。
3. **固定底部的按钮**：用 `position: fixed; bottom: 0` 时，记得给 `bottom` 留出安全区，例如：  
   `bottom: constant(safe-area-inset-bottom); bottom: env(safe-area-inset-bottom);`  
   或给按钮容器加 `padding-bottom: env(safe-area-inset-bottom)`。

---

## 四、自定义导航栏时

若使用自定义导航栏（隐藏系统导航栏），需要自己留出「状态栏高度」：

```js
// 在页面的 onLoad 或 attached 里
const sys = wx.getSystemInfoSync();
this.setData({
  statusBarHeight: sys.statusBarHeight,  // 单位 px，用于占位高度
  menuButton: wx.getMenuButtonBoundingClientRect(),  // 胶囊位置，用于自定义导航栏布局
});
```

在 WXML 里给导航栏容器设高度时，用 `style="height: {{statusBarHeight}}px"` 或对应 rpx 换算，避免内容顶到状态栏。

---

## 五、图片与比例

- **头像、图标**：建议固定宽高（rpx），用 `mode="aspectFill"` 或 `aspectFit` 控制裁剪/留白。
- **Banner、大图**：可用宽度 100% 或 750rpx，高度按设计比例用 rpx，或 `mode="widthFix"` 按宽度等比缩放。

---

## 六、自检清单

- [ ] 所有布局尺寸、字号、间距使用 **rpx**。
- [ ] 有 TabBar 的页面内容区 **padding-bottom** 含 `env(safe-area-inset-bottom)`。
- [ ] 自定义 TabBar 或固定底部栏已加 **底部安全区**。
- [ ] 自定义导航栏时已预留 **状态栏高度**。
- [ ] 在 **多机型预览**（小屏 iPhone SE、大屏 Android、iPhone 带刘海）下各点一遍主要页面，确认无遮挡、无错位。

按以上约定开发，即可在现有基础上适配绝大多数用户机型。
