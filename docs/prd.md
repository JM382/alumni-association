校友服务小程序需求文档

1：主要功能
一：首页
界面展示内容
1.顶部 Banner 区：轮播展示母校最新动态、校友活动预告、校园风光、合作福利推广（如酒店 / 航空优惠）。
2.快捷功能入口区（8 个核心入口，图标 + 文字）：
电子校友卡、返校预约、校友福利、捐赠通道
校友企业、校友联谊、校友资源、专家资源
3.动态推送区（滚动列表）：
分类展示：校友故事、母校新闻、行业动态、校友企业招聘、活动预告
每条动态包含：标题、缩略图、发布时间、浏览量
二：校友服务
界面展示内容
1.服务分类标签（顶部横向滑动）：
校友福利、返校服务、捐赠通道、其他服务
2.各分类对应内容：
【校友福利】（默认展示）：
卡片式展示所有合作福利（酒店特权、顺丰优惠、瑞幸咖啡、超星图书馆、一嗨租车、南航优惠）
每张卡片包含：福利名称、核心权益、合作方 Logo、“立即使用” 按钮（跳转至对应小程序 / 页面）
【返校服务】：
预约入校：填写姓名、校友卡号、预计到访时间、同行人数的表单
校园导览：电子地图（标注教学楼、食堂、纪念馆、招待所位置）
住宿推荐：校内招待所预订入口、合作酒店优惠跳转
【捐赠通道】：
捐赠项目分类：助学基金、校园建设、科研支持（带项目介绍 + 捐赠目标进度）
捐赠金额选择：固定金额（50/100/200 元）+ 自定义金额
支付方式：微信支付、支付宝、银联（图标展示）
捐赠后即时生成电子版捐赠证书（可保存 / 分享）
三：资讯
3.1 新闻分类
分类列表：母校新闻、校友会通知、行业动态、校友故事、政策资讯
交互逻辑：顶部 Tab 切换分类，默认显示 “全部新闻”
3.2 新闻详情页
展示内容：标题、发布时间、来源、正文（图文结合）、相关新闻推荐
交互功能：支持点赞、收藏、分享（微信 / 朋友圈 / QQ）、评论（需登录会员账号）
设计要求：正文文字字号 16px，行间距 1.5 倍，图片自适应屏幕宽度
3.3 新闻发布（管理员 / 会员权限）
管理员发布：支持发布所有分类新闻，可上传图片 / 视频、设置置顶 / 推荐、定时发布
会员发布：仅支持发布 “校友故事” 分类内容，需填写标题、正文、上传图片，提交后经管理员审核方可发布
交互逻辑：发布页面提供富文本编辑器（支持加粗、换行、插入图片），发布成功后跳转至新闻
2：界面样式
必须使用Tdesign Weixing 这个现成的界面工具包来做，让小程序的按钮，列表，输入框看起来风格统一，简洁，好看（参考：https://tdesign.tencent.com/miniprogram/getting-started）
