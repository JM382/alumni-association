校友服务小程序 · 原型页面总览

使用 HTML + Tailwind CSS 按页面拆分实现原型，index.html 通过多个 iframe 平铺嵌入各页面文件，不使用链接跳转，便于一次性对比查看。

设计风格：Tailwind + TDesign 风格组件

首页（home.html）

Banner + 快捷入口 + 动态推送

校友服务（services.html）

校友福利 / 返校服务 / 捐赠通道

资讯列表（news.html）

顶部 Tab 分类 + 列表卡片

新闻详情（news-detail.html）

标题 + 发布时间 + 来源 + 正文 + 交互

新闻发布（news-publish.html）

管理员 / 会员发布入口 + 富文本编辑器占位
